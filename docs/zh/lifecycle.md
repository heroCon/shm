# 生命周期

一个 topic 是一块 `shm_open` 区域。创建者初始化头、空闲列表、槽和组队列，然后把初始化状态写成就绪。别的进程附加时如果还没就绪，会在 `initialization_timeout` 内等待。

端点构造时在自己的槽字节上拿一把独占 OFD 锁。锁由内核在进程死亡时释放，所以能锁上这个字节就说明主人已经不在。构造函数如果撞上正在 `recover()` 的维护锁，会等一小段时间再扫描，而不是立刻报告槽表已满。

析构是优雅回收：发布者清掉自己的钉住掩码，订阅者离开组，贷款表里的持有者位被清除，槽回到空闲。非优雅回收（`collect_garbage()` 发现主人已死）还会修队列：填墓碑、释放已声明的单元、重算正在投递的块，并对至少一次的组重新入队。

`Topic::destroy(name)` 删除命名区域。仍映射着它的进程继续使用自己的映射，直到它们退出。
